
# System Design: Scanner reader 


## 1. Что должен делать продукт?

Продукт представляет из себя платформу для **сбора, обработки и хранения данных** с удаленных физических устройств.

### 1.1. Основные функции:
* Прием данных 
* Валидация 
* Хранение данных 
* Уведомления 


### 1.2. Сценарии взаимодействия:
1. Отправка данных устройством:
* Устройство собирает данные -> Формирует JSON пакет -> Отправляет POST-запрос на API-сервер -> Получает подтверждение (`200 OK`)
2. Чтение данных (Дашборд):
* Юзер открывает веб-интерфейс -> Запрашивает историю измерение за прошедший период -> Получает данные в виде графика за выбранный период.
3. Получение уведомлений: 
* Устройство читает данные с датчиков -> Формирует JSON пакет -> Отправляет POST- запрос на API-сервер -> Сервер принимает пакет и проверят показания на превышение критических значений -> отправляет уведомление (Telegram, Email) в случае превышения предельных показаний.


## 2. Сущности

- Устройство

## 3. Свойства сущностей

 #### 1. Пользователь / User
* `id` (Integer, PK) -Уникальный идентификатор пользователя.
* `email` (String, Unique) - логин для аутентификации.
* `hashed_password` (String) - Хэш пароль.
* `created_at` (TimeStamp) - Дата регистрации устройства в системе. 

#### 2. Устройство / Device 
* `id`(Integer, PK) - Уникальный идентификатор устройства.
* `device_id` (String, Unique) - Аппаратный серийный номер или MAC-адрес. 
* `name` (String) - Имя устройства.
* `user_id` (Integer, FK) - ID владельца устройства. 
* `status` (String) - Статус устройства.
* `created_at` (TimeStamp) - Дата регистрации устройства.

#### 3. Показания / Measurement 
* `id` (BigInt, PK) — Уникальный ID записи. 
* `device_id` (Integer, FK) — ID устройства, отправившего данные.
*   `timestamp` (Timestamp, Indexed) — Время снятия показаний (переданное датчиком или проставленное API). 
* `metrics` (JSONB / Map) — Набор параметров. Например: `{"temperature": 23.5, "humidity": 65, "battery": 98}`. 
* `received_at` (Timestamp) — Время получения запроса сервером (для отслеживания задержек сети).
